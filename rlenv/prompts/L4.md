The fix: replace each token's score s_y by s_y - s_bar(h), multiplied by the
same advantage A. Its expectation is exactly Cov_q(A, s_y | h): the drift is
gone, and on-policy the change is zero. It uses no importance ratios.

To implement it with one backward pass, use the surrogate (sg = stop-gradient)

    loss_t = -A * ( log p(y_t|h) - sum_v sg[q(v|h)] log p(v|h) )

whose gradient is -A * (s_y - s_bar(h)). If only the sampler's top-k head H
is available, model q's tail as proportional to p, with mass ratio
rho = q_tail / p_tail. Since sum_v p_v grad log p_v = 0, the tail contributes
no gradient and

    loss_t = -A * ( log p(y_t|h) - sum_{v in H} sg[q_v - rho p_v] log p_v ).

Keep the sampled token's own log p even when it is outside the head.
